TKA Mod Manager

Your complete guide to managing mods for The Killing Antidote

UE4SS & archive structure (must read)

If a mod requires UE4SS (or uses UE4SS scripts), you must provide a config.ini file with this exact structure:

[Mod] script=name_of_script_folder

The script folder must be placed inside Your Mod folder, for example:

📦 archive.zip ├── Mainfile.pak ├── 📁 scriptfolder(contains "Scripts" folder and etc...) │ └── Scripts │ └──etc... ├── config.ini

ZIP / RAR / 7z archive rules:

  • .pak and .mp4 files must be directly inside the archive (not inside a folder).
  • If your mod has multiple variants (user must pick one), structure the archive like this:
📦 archive.zip ├── main_file.pak ├── 📁 folder_option1 │ └── file1.pak ├── 📁 folder_option2 │ └── file2.pak

❌ Wrong structure (do NOT use):

📦 archive.zip ├── 📁 some_folder │ └── main_file.pak ├── 📁 folder_option1 │ └── file1.pak ├── 📁 folder_option2 │ └── file2.pak
📦 archive.zip ├──📁 some_folder │ └── main_file.pak │ 📁 folder_option1 │ └── file1.pak │ 📁 folder_option2 │ └── file2.pak

For .mp4 files: it’s okay, you can place them anywhere you want inside the archive.

Correct structure ensures mods are detected and installed without issues.

Add Mods Quick

Click Add Mod or drag & drop .zip / .rar files onto the app.

You can add multiple files at once. Mods are extracted automatically to the mods folder.

Select Mod Folder

If a package contains multiple folders, choose the one containing the main files (.pak).

This folder will appear in your mods directory automatically.

Enabling Mods

Use the toggle to enable or disable a mod.

Disabling Mods

Toggle off a mod to disable it. All installed files of that mod will be removed.

Deleting Mods

Right-click a mod in the list → Delete Mod. This removes it completely from your mods list.

Settings Important

Configure the Game Path where TheKillingAntidote.exe is located and choose language.

Also you can choose your custom language.

Open Mods Folder

Click on All Mods to view all your imported mods.

Right Click on any mod to open the content of imported mod folder.

Click on Installed Mods to view all your installed mods inside the game.

Drag & Drop

Drag .zip, .rar or .7z files directly onto the app to add mods.

Notes & Tips

  • Only .pak and .mp4 files are supported.
  • Choose carefully if multiple folders appear.
  • Backup mods before overwriting.
  • You can archive all .pak and .mp4 files in 1 zip/rar/7z file and install at the same time.
