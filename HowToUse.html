UE4SS · archive structure must read

If a mod requires UE4SS (or uses UE4SS scripts), you must provide a config.ini with this structure:

[Mod]
script=name_of_script_folder

Script folder must be placed inside Your Mod folder:

📦 archive.zip
├── Mainfile.pak
├── 📁 scriptfolder (contains "Scripts" folder etc.)
│ └── Scripts
│ └── ...
├── config.ini

ZIP / RAR / 7z rules:

  • .pak and .mp4 files must be directly inside the archive (not in a subfolder).
  • If your mod has multiple variants, structure like this:
✅ Correct
📦 archive.zip
├── main_file.pak
├── 📁 folder_option1
│ └── file1.pak
├── 📁 folder_option2
│ └── file2.pak
❌ Wrong (do NOT use)
📦 archive.zip
├── 📁 some_folder
│ └── main_file.pak
├── 📁 folder_option1
│ └── file1.pak

mp4 files can be placed anywhere inside the archive.

Correct structure ensures detection & installation without issues.
