Everything you need to install, manage, and update mods for The Killing Antidote — fast and without headaches.

Windows 8 and above 64-bit optimized .zip · .rar · .7z
Archive structure UE4SS · must read before packaging
Must read

If your mod requires UE4SS (or uses UE4SS scripts), include a config.ini at the root of the archive with this content:

[Mod]
script=name_of_script_folder

The script folder must sit directly inside your mod folder — not nested further:

📦 archive.zip
├── Mainfile.pak
├── 📁 scriptfolder/
│   ├── Scripts/
│   └── ...
└── config.ini

Rules for .zip / .rar / .7z packaging:

  • .pak and .mp4 files must be at the root of the archive — not inside a subfolder.
  • .mp4 files may be placed anywhere inside the archive.
  • Mods with multiple variants must use named sub-folders at the root (not nested under a parent folder).
✓ Correct
📦 archive.zip
├── main_file.pak
├── 📁 folder_option1/
│   └── file1.pak
└── 📁 folder_option2/
    └── file2.pak
✗ Wrong — do not use
📦 archive.zip
└── 📁 some_folder/
    ├── main_file.pak
    └── 📁 folder_option1/
        └── file1.pak
Correct structure ensures the app detects and installs your mod without any issues.
Features What the mod manager can do

Add mods drag & drop

Click Add Mod or drag and drop a .zip, .rar, or .7z directly onto the app. Add multiple files at once.

Select mod folder auto-detected

If a package contains multiple folders, pick the one holding your main .pak files. The app highlights the right one automatically.

Enable / Disable

Flip the toggle to enable or disable any mod instantly. Disabling removes the installed files from your game folder cleanly.

Delete mods

Right-click any mod → Delete Mod. Removes it completely from your list and cleans up its files.

Settings game path

Point the app to TheKillingAntidote.exe, choose a custom mods path, and pick your interface language.

Open Mods folder

Click All Mods to browse all imported mods. Right-click any entry to jump straight to its folder on disk.

Open ~Mods folder

Click Installed Mods to open the game's active mods directory and see exactly what's live.

64-bit optimized next-gen

Built specifically for modern 64-bit systems — faster loading times, lower memory overhead, and noticeably smoother operation compared to 32-bit equivalents. No extra setup required.

Notes & tips Keep these in mind
Only .pak and .mp4 file types are supported.
When multiple folders appear during install, pick carefully — choose the one with your main files.
Always back up your mods before overwriting with a new version.
You can archive multiple .pak and .mp4 files into a single zip/rar/7z and install them all at once.

How to update

Copy and paste the new version's files over the existing ones and replace all when prompted. That's it — no uninstall needed.
