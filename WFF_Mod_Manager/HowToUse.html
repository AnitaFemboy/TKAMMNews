VERY IMPORTANT: Enable Mods First

To activate any mods, you must first install Wuchang Mod Enabler from Nexus Mods:

Wuchang Mod Enabler on Nexus

After installing and enabling it, you can manage your custom mod list seamlessly.

UE4SS & Archive Structure (must read)

If a mod requires UE4SS (or uses UE4SS scripts), you must provide a config.ini with this exact structure:

[Mod] script=name_of_script_folder

The script folder must be placed inside Your Mod folder, for example:

📦 archive.zip ├── Mainfile.pak ├── 📁 scriptfolder (contains "Scripts" folder, etc...) │ └── Scripts │ └── etc... ├── config.ini

ZIP / RAR / 7z archive rules:

  • .pak files must be directly inside the archive (not inside a nested folder).
  • If your mod has multiple variants (user must pick one), structure like this:
📦 archive.zip ├── main_file.pak ├── 📁 folder_option1 │ └── file1.pak ├── 📁 folder_option2 │ └── file2.pak

❌ Wrong structure (do NOT use):

📦 archive.zip ├── 📁 some_folder │ └── main_file.pak ├── 📁 folder_option1 │ └── file1.pak

Correct structure ensures mods are detected and installed flawlessly.

Add Mods Quick

Click Add Mod or drag & drop .zip / .rar files onto the app.

Add multiple files at once; mods extract automatically to the mods folder.

Select Mod Folder

If a package contains multiple folders, choose the one containing main files (.pak).

This folder will appear in your mods directory automatically.

Enabling Mods

Use the toggle to enable a mod – instant activation.

Disabling Mods

Toggle off to disable a mod. All installed files of that mod will be removed.

Deleting Mods

Right-click a mod → Delete Mod. Removes it completely from your list.

Settings Important

Set the Game Path where WuchangFallenFeathers.exe is located, choose language.

You can also select a custom language.

Open Mods Folder

Click All Mods to view imported mods. Right-click any mod to open its folder.

Installed Mods shows active mods inside the game.

Drag & Drop

Drag .zip, .rar or .7z files directly onto the app to add mods.
